## Идея приложения
- Создать мобильное приложения для создания цикличных задач, обеспечивать регулярность их выполнения. Это может быть ежедневная утренняя зарядка, еженедельный обзор отчетности по работе, так и ежеквартальная замена фильтров для питьевой воды дома.


## Основной функционал приложения
- Создавать задачи, задавать их цикличность, отслеживать наступление цикла, выполнять задачи, получать баллы по заданной логике, чем точнее соблюдать цикличность тем больше баллов.
- Отслеживать статистику выполнения задач, расчитывать общее количество баллов и коэффициент нахождения в установленном режиме.


## Структура экранов:
- TabBarController -> NavigationController -> 4 экрана:
- 1) Главный для отображения статистики / ViewController
- 2) Управление задачами / TableViewController c кастомной TableViewCell + AlertController для создания задачи
- 3) Журнал для отображения всех действий / TableViewController c кастомной TableViewCell + окно для редактирования записей журнала / ViewController
- 4) Настройки приложения / TableViewController


## Хранение данных:
- Локально. CoreData для задач и журнала задач. UserDefaults для настроек.

## Логика калькуляции баллов
- Коэффициент нахождения в заданном режиме рассчитывается как отношение суммы полученных (заработанных за выполнение) баллов к их максимально возможному результату (сумме плановых значений).
- Максимальное количество баллов можно получить при точном выполнении заданного цикла. 1 балл = 1 час. Например, если у задачи "делать утреннюю зарядку" стоит цикличность "Ежедневно", то плановое значение будет 24, а фактическое начнет высчитываться с момента активации задачи. До наступления первого цикла (0-24 часа) баллы прибалвяются до максимально-заданного значения 0->24, второй цикл (24-48 часов) убывают 24->0, третий цикл - отрицательные значения <0.
- При создании и остановке задачи баллы не начисляются
- При первой активации задачи, после ее создания, начисляются приветственные баллы равные одному плановому значению. Если задача была остановлена, приветственные баллы вычитаются.
