#** Логика калькуляции:


###** СОЗДАНИЕ ЗАДАЧИ
- При помощи отдельного контроллера создается задача, указывается название и ее цикличность, расчитываемая в секундах. Задача приобретает статус "Созданная", никакие баллы не начисляются, задача становиться доступной в общем списке задач.
- Задачу можно активировать при помощи длительного нажатия через подтверждение на alertController, задача приобретает статус "Активная", начисляются приветвенные баллы в размере полного цикла задачи. Кратковременные нажатия не работают.
- Активную задачу можно выполнить кратковременным нажатие через подтверждение на alertController и получить баллы равные прошедшему времени после активации, но не более полного цикла, при просрочке задачи начинается обратный отсчет, негативный результат можно получить при просрочке задачи более чем на 1 цикл, задаче присваивается статус "Активная".
- Активную задачу можно деактивировать длительным нажатием через подтверждение на alertController, при этом баллы не начисляются, присваивается статус "Неактивный".


- При создании задачи устанавливается цикличность, которая расчитывается в секундах.
- После первого запуска задача принимает статус "Active", присваиваются приветственные баллы равные полной цикличности задачи.
- Если задача была деактивирована после ее запуска, то приветственные баллы сгорают.
- Елси задача была деактивирована после ее повторных запусков, то обнуляется последний счетчик, задача переходит в статус "не активная".
- Если задача была повторно активирована после ее деактивации, то приветственные баллы не начисляются.
- При повторном выполнении задачи присваиваются баллы равные времени, прошедшие с момента последнего выполнения задачи.
- Максимальные баллы можно получить при точном повторении цикличности.
- Если задача просрочена, то отрицательное время минусуется от набранного, т.е отрицательные баллы можно получить просрочив активность на срок более 1 цикла.


###** TASK STATUS:
- Статус "Created": Присваивается задаче только после ее создания.
- Статус "First Run": Присваивается задаче после ее первичной активации.
- Статус "Active": Присваивается задаче после ее повторной активации или активации из состояня "Passive" и "Changed".
- Статус "Passive": Присваивается задаче после ее деактивации.
- Статус "Changed after Created": Присваивается задаче после изменения цикличности в состоянии "Created". 


###** TASK CRUD:
- Создание задачи: баллы не начисляются, задача отображается в общем списке задач со статусом "Created".
- Удалении задачи: история удаляется, статистика исключается из калькуляции.
- Изменение названия задачи: история меняет свое название, по-прежнему участвует в калькуляции.
- Изменение цикличности: история не меняется, баллы не начисляются, задача принимает статус "Changed".

###** Изменение статуса:
- Created -> Run: Меняет статус при первичной активации задачи, начисляются приветственные баллы в размере полного цикла.
- Created -> Active: Невозможен. Статус "Active" присваивается только после повторной активации задачи.
- Created -> Passive: Невозможен. Так как при статусе задачи "Created" ползунок выключен, его нажатие переводит
