#  Декабрь 2025

## **Дипломная работа курса Нетология "IOS-разработчик с нуля"**
## **Название приложения: REGIME**

## **Идея приложения**

- Приложение предназначено для создания своего режима и определения уровня соответствия ему;
- В приложении создаются цикличные задачи для контроля их выполнения;
- При точном выполнении заданной цикличности начислять максимальные баллы;
- При неточном выполнении заданной цикличности баллы уменьшаются пропорционально времени отклонения;
- При отклонении более двух циклов баллы вычитаются;
- На главном экране можно посмотреть статистику и показатель нахождения в заданном режиме.


## **Архитектура экранов**

- Построена кодом, без использования Storyboards (кроме LaunchScreen)

- Запуск приложения -> LaunchScreen

- Окно LogIN -> Окно регистрации (ViewController in NavController)

TabBarController with:
- MainScreen - основной экран со статистикой (ViewController in NavController)
- Tasks - экран управления задачами (TableViewController in NavController)
- Logs - экран истории логов и их управления (TableViewController in NavController)
- Settings - экран настроек (TableViewController in NavController)


## **Функционал пользователя**

- Экран LogIN: ввести логин и пароль в соответствующие поля, нажать кнопку входа или регистрации.
- Экран Registration: ввести логин и пароль в соотвествующие поля, зарегистрировать пользователя.
- Экран MainScreen: посмотреть предложенную статистику и достижения, разлогиниться.
- Экран Tasks: создать, выполнить, остановить, изменить, удалить задачу + настроить сортировку.
- Экран Logs: изменить, удалить лог или все логи + настроить сортировку.
- Экран Settings: установить пороговые значения для достижений.


## **Хранение данных**

- Логин - UserDefaults
- Пароль - Keychain
- Задачи, логи - Core Data
- Настройки - UserDefaults


## **Логика калькуляции**

- При помощи отдельного контроллера создается задача, указывается название и ее цикличность, расчитываемая в секундах. Задача приобретает статус "Созданная", никакие баллы не начисляются, задача становиться доступной в общем списке задач.

- Задачу можно активировать при помощи короткого нажатия + через подтверждение на alertController, задача приобретает статус "Активная", начисляются приветвенные баллы в размере полного цикла задачи.

- Активную задачу можно выполнить кратковременным нажатие + через подтверждение на alertController и получить баллы равные прошедшему времени после активации, но не более полного цикла, при просрочке задачи начинается обратный отсчет, негативный результат можно получить при просрочке задачи более чем на 2 цикла, задаче присваивается статус "Активная".

- Активную задачу можно остановить коротким нажатием + через подтверждение на alertController, при этом приветственные баллы вычитаются, присваивается статус "Остановленный".
